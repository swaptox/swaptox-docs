# Smart Contracts Overview

SwaptoX smart contracts provide the on-chain execution layer for token swaps across decentralized exchanges (DEXs). The Router aggregates liquidity from supported protocols, executes optimized swap routes, and supports multi-hop and split routing to help users achieve better swap outputs.

The contracts also include fee management and access control mechanisms to manage protocol fees and restrict sensitive administrative operations.
