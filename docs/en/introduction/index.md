# Introduction

SwaptoX helps applications add token swaps through an embeddable widget, wallet connection tools, public APIs, and on-chain Router contracts. This documentation explains how these parts fit together and how to start an integration.

## Start here

- [Product overview](./overview): understand the main components and the swap flow.
- [Getting started](./getting-started): choose an integration path and create a first widget.

## Browse the technical guides

- [SDKs](/sdk/): connect a wallet with `swaptox-connect` or embed a swap interface with `swaptox-widget`.
- [API](/api/): retrieve supported networks, token information, prices, quotes, and route data.
- [Contracts](/contracts/): review Router calls, deployments, fees, and security information.
