# Frequently asked questions

## Which integration should I choose?

Use [`swaptox-widget`](/sdk/swaptox-widget/) when you want to embed a ready-made swap interface. Pair it with `swaptox-connect` using the [integration guide](/sdk/swaptox-widget/connect-integration) to share wallet state and transaction handling. If you need a custom interface, use the [API](/api/) and [Router contracts](/contracts/router) directly.

## How do I check which networks are supported?

Use the [supported chains endpoint](https://api-v2.swaptox.com/supported-chains) for the current list. Use the returned network name in the API URL and SDK configuration.

## Need help with your integration?

Visit [app.swaptox.com](https://app.swaptox.com) or [m.swaptox.com](https://m.swaptox.com) and scroll to the bottom of the page for contact details. You can also join a SwaptoX community group to ask questions and get help.
