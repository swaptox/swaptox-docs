# SwaptoX 介绍

SwaptoX 为应用接入代币兑换提供嵌入式 Widget、钱包连接工具、公开 API 和链上 Router 合约。本文档介绍这些组件的关系，并带你开始集成。

## 从这里开始

- [产品概览](./overview)：了解 SwaptoX 的主要组件和兑换流程。
- [快速开始](./getting-started)：选择接入方式并创建第一个 Widget。

## 查看技术文档

- [SDK](/zh/sdk/)：使用 `swaptox-connect` 连接钱包，或用 `swaptox-widget` 嵌入兑换界面。
- [API](/zh/api/)：获取支持的网络、代币信息、价格、报价和路由数据。
- [合约](/zh/contracts/)：了解 Router 调用、部署地址、费用和安全信息。
