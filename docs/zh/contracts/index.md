# 合约概览

SwaptoX 智能合约为跨去中心化交易所（DEX）的代币兑换提供链上执行层。Router 聚合受支持协议的流动性，执行优化后的兑换路径，并支持多跳与拆分路由，帮助用户获得更优的兑换结果。

合约还包含费用管理和访问控制机制，用于管理协议费用并限制敏感管理操作。
