# 费用机制

Router 提供只读方法 `getSwapFeeBP(account, token)`，用于查询账户和代币对应的兑换费率。费率以 BP（基点）表示：

- `10,000 BP = 100%`
- `20 BP = 0.2%`

基础费率 `baseFee` 为 `20 BP`，即 `0.2%`。传入账户地址和代币地址可查询对应费率。

## 邀请分成

`swap` 方法接收 `referral` 邀请者地址。邀请者可获得 **30%–50% 的手续费分成**。

## 网络费用

交易还需要支付所在网络的 Gas 费用。实际 Gas 成本随网络状态和交易执行路径而变化。
