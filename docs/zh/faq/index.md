# 常见问题

## 应该选择哪种接入方式？

需要直接嵌入兑换界面时，使用 [`swaptox-widget`](/zh/sdk/swaptox-widget/)。需要共享钱包状态和交易处理时，按 [Widget 与 swaptox-connect 集成指南](/zh/sdk/swaptox-widget/connect-integration) 搭配使用。需要自定义界面时，可以直接使用 [API](/zh/api/) 和 [Router 合约](/zh/contracts/router)。

## 如何确认支持哪些网络？

通过[支持的网络接口](https://api-v2.swaptox.com/supported-chains)查看当前列表，并在 API 地址和 SDK 配置中使用返回的网络名称。

## 接入过程中需要帮助？

访问 [app.swaptox.com](https://app.swaptox.com) 或 [m.swaptox.com](https://m.swaptox.com)，滚动到页面底部查看联系方式。你也可以加入 SwaptoX 社群，向团队和其他用户咨询。
